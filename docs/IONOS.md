# Jimmy bei IONOS einbinden

1. Demo prüfen: https://galgental9ps-png.github.io/chatavatar-universal/
2. Einen Bereich für eigenes HTML/JavaScript im Editor öffnen, sofern Ihr Produkt ihn anbietet.
3. Einmal einfügen und Seite veröffentlichen:

```html
<script src="https://galgental9ps-png.github.io/chatavatar-universal/avatar.js" defer></script>
```

Es muss nichts bei IONOS hochgeladen werden. Dateien und Wissen bleiben bei GitHub Pages.

Falls der Editor Scripts entfernt oder isoliert, eine eingebettete Seite nutzen:

```html
<iframe src="https://galgental9ps-png.github.io/chatavatar-universal/embed.html"
  title="Jimmy – Parkbegleiter" width="100%" height="740"
  style="border:0;max-width:100%"></iframe>
```

Die Figur bleibt im eingebetteten Rahmen. Freies Laufen auf der gesamten Seite setzt voraus, dass Ihr IONOS-Produkt das Script direkt im Seitendokument ausführt.

Wissensänderungen unter admin.html vornehmen, auf GitHub speichern, erfolgreiche Pages-Veröffentlichung abwarten und Park-Webseite neu laden.
