Wissensdaten hochladen

Laden Sie ein von ChatGPT vorbereitetes Wissenspaket oder eigene Inhalte. Alles wird zunächst lokal im Browser verarbeitet.

Ein JSON-Paket ersetzt den aktuellen Entwurf. Markdown, TXT und CSV ergänzen neue Einträge in „Importierte Inhalte“. Diese sind zunächst deaktiviert: Prüfen und aktivieren Sie sie im Editor.

So versteht Jimmy Ihre Texte

Markdown: Jede Überschrift wird eine Frage; der folgende Text wird die Antwort. CSV braucht die Spalten Frage und Antwort, optional Quelle. JSON bietet das komplette Paket mit Kategorien, Folgefragen und Quellen.

PDF und Word bitte zuerst als Text exportieren. Die Schnittstelle liest keine beliebigen Dokumente mit KI aus.

GitHub-Zugang

Die Verwaltungsseite ist ein statischer Editor. Erst Ihr GitHub-Zugang erlaubt es, den zentralen Wissensstand zu verändern. Webseitenbesucher können keine Daten überschreiben.

Noch nicht verbunden. Ihr lokaler Entwurf ist unabhängig davon bearbeitbar.

Schreibt JSON und Offlinepaket gemeinsam in einen Commit. Danach benötigt GitHub Pages Zeit für die Veröffentlichung. Bereits offene Webseiten bitte neu laden.

Einmal einrichten

  1. 1In GitHub einen Fine-grained Personal Access Token anlegen. Nur „chatavatar-universal“ auswählen und unter Repository permissions „Contents: Read and write“ setzen.
  2. 2Hier verbinden. Dabei wird die aktuelle Wissensdatei geladen. Vorhandene lokale Änderungen können Sie zuvor als JSON sichern.
  3. 3Wissen bearbeiten oder importieren, Antworten testen und „Auf GitHub speichern“ anklicken.
  4. 4Unter Repository → Settings → Pages als Quelle GitHub Actions wählen. Der mitgelieferte Pages-Workflow veröffentlicht nach erfolgreichen Tests bei jedem Push auf main. Danach den von GitHub angezeigten Seitenlink benutzen.
Diese Datenbank ist öffentlich. Veröffentlichen Sie hier ausschließlich Antworten und Dateien, die Websitebesucher lesen dürfen. Der GitHub-Token bleibt im Arbeitsspeicher des Editors; er gehört niemals in den Einbindungscode.

Sie können das JSON auch exportieren und über GitHubs Dateiupload austauschen. Für einen lokalen Start ist kein Token erforderlich.

Wissensdatei und Schnittstelle
Standardmäßig lädt das Widget knowledge/jimmys-funpark.json relativ zum Script. Eine andere Organisation binden Sie mit data-knowledge="https://…/firma.json" ein. Die JSON-Datei muss öffentlich lesbar sein; bei einer anderen Domain muss der Server CORS erlauben.
Direkt in JavaScript steuern
// Nach dem Laden:
JimmyChatAvatar.instance.open();
JimmyChatAvatar.instance.answer('zeiten');
// Eigenes geprüftes Paket in der laufenden Figur testen:
JimmyChatAvatar.instance.setKnowledge(meinWissenspaket);
Die Figur nutzt Shadow DOM und verändert keine Styles Ihrer Webseite. Sie ist ziehbar, läuft am unteren Seitenrand, zeigt Sprechblasen und stoppt beim geöffneten Antwortfenster. „Pause“, Ausblenden und reduzierte Bewegung werden unterstützt.
